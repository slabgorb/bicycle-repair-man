# Bicycle Repair Man

<p align="center">
  <img src="assets/hero.png" alt="Bicycle Repair Man — Monty Python's Flying Circus, 1969" width="540">
</p>

A Claude Code plugin: role-bounded slash commands with per-role persistent memory.

Sits between [superpowers](https://github.com/obra/superpowers) (the skills — *what* to do) and [zeitgoose](https://github.com/slabgorb/zeitgoose) (the persona — *what voice*). BRM is the role layer: *who* is driving, and what they remember.

**Status:** in design. See [`CLAUDE.md`](CLAUDE.md) for the project brief.
